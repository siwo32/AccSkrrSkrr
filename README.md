# MiM AccSkrrSkrr

首元のヘッドホンやゴーグルに揺れを設定するUnity Editorツールです。
このリポジトリはバージョン情報・更新案内を公開します。

- [配布・商品ページ（BOOTH）](https://howareyu.booth.pm/items/8909830)
- [お問い合わせ・質問はこちらから（公式Discord）](https://discord.gg/cpu6ZFRJE)
- [更新情報JSON](https://siwo32.github.io/AccSkrrSkrr/accskrrskrr_version.json)

無料版：独立した小物の揺れを設定できます。
有償版：衣装に組み込まれたメッシュにも対応します。

使い方はツール内の「使い方」から画像付きガイドをご覧ください。お問い合わせ時は、現在インポートされているバージョン、無料版／有償版、操作手順、画面やメッセージをお知らせください。

## 更新情報の管理

`accskrrskrr_version.json` の `version` と `build` を配布物に合わせます。新しい配布物が公開された後に `build` を増やし、`changes` と `changes_en` に変更点を記載してください。

Tool downloads are available on BOOTH. Questions and support: the official Discord server above.
